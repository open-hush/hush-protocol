## Users — JWT Bearer

### Access token

> TODO(phase-1): Algorithm `EdDSA` over Ed25519. TTL 15 minutes. Claims: `sub`, `iat`, `exp`, `jti`. Audience is implicit (`api.open-hush.com`).

### Refresh token

> TODO(phase-1): Opaque random string, 32 bytes base64url. Stored hashed (Argon2id) server-side. TTL 30 days.

### Rotation

> TODO(phase-1): Refresh is single-use; using a refresh token returns a new pair and invalidates the previous refresh. Reuse triggers a session-wide revoke.

## Error responses

| Status | Code | When |
|---|---|---|
| 401 | `unauthorized` | Missing or malformed auth header |
| 401 | `invalid_signature` | HMAC verification failed |
| 401 | `expired_token` | JWT past `exp` |
| 401 | `invalid_credentials` | Wrong email/password on login |
